    Break it and watch it heal

    Partition and Heal are the buttons on each node. To crash and restart a node (Docker Compose):
    docker compose kill node2 docker compose start node2
    A killed node goes alive → suspect (1.5 s) → dead (4 s) on the others; a restarted one joins, resyncs, then turns ready.
